# 电商图片提取下载器

一个 Microsoft Edge（Chromium）浏览器插件，用于在电商商品详情页一键提取所有图片，在新页面中预览勾选，并以 PNG 格式批量下载。

## 功能

- 在支持的电商商品详情页右下角显示「获取图片」浮动按钮。
- 点击后自动提取页面中的所有商品图片，包含：
  - 常规 `<img>` 图片
  - 懒加载图片（`data-src`、`data-original`、`data-lazyload`、`data-ks-lazyload` 等）
  - CSS 背景图
  - `srcset` 高清图（优先取最大分辨率）
- 在新标签页中以网格形式展示所有图片，支持单张勾选、全选、反选、清空。
- 支持缩略图大图预览。
- 下载时将图片统一转换为 PNG 格式，支持批量下载。

## 支持的平台

- 淘宝（taobao.com / tmall.com）
- 京东（jd.com）
- 拼多多商家版（mms.pinduoduo.com，及 pinduoduo.com）

## 安装方法

1. 打开 Edge 浏览器，在地址栏输入 `edge://extensions` 并回车。
2. 打开左下角的「开发人员模式」开关。
3. 点击「加载解压缩的扩展」。
4. 选择本项目的根目录（即包含 `manifest.json` 的目录）。
5. 安装完成后，访问支持的电商商品详情页，页面右下角会出现「获取图片」按钮。

## 使用说明

1. 进入淘宝 / 京东 / 拼多多商家版的商品详情页。
2. 点击右下角的「获取图片」按钮。
3. 插件会滚动页面以触发懒加载，然后提取所有图片并打开结果页。
4. 在结果页中勾选需要的图片（可全选 / 反选 / 清空）。
5. 点击「下载所选图片」，图片会以 PNG 格式保存到下载目录下的 `电商图片` 文件夹中。

## 项目结构

```
.
├── manifest.json     # 插件清单（Manifest V3）
├── content.js        # 内容脚本：注入按钮 + 提取图片
├── background.js     # Service Worker：打开/复用预览页
├── viewer.html       # 结果预览页
├── viewer.css        # 结果页样式
├── viewer.js         # 结果页逻辑：展示、勾选、下载、PNG 转换
├── make-icons.js     # 图标生成脚本（可选）
└── icons/            # 插件图标
```

## 重新生成图标

```bash
node make-icons.js
```

## 说明与已知限制

- 提取逻辑在顶层页面运行，部分嵌套在跨域 iframe 中的详情图可能无法抓取。
- 超大尺寸图片在转换为 PNG 时若超过浏览器 Canvas 限制，会自动等比缩放。
- 动图（GIF/WebP 动图）转换为 PNG 后仅保留首帧。
