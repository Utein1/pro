产品介绍

为电商从业者、运营与设计师打造的轻量图片采集工具。

解决什么

手动逐张保存商品图费时费力，尤其面对懒加载的长图与主图轮播。本插件在详情页一键抓取全部图片， 集中预览后再批量下载，省去反复右键「另存为」的麻烦。

适用场景

商品素材归档、竞品图片分析、详情页设计参考、图片二次编辑与整理。无论是运营、客服还是设计， 都能快速拿到统一的 PNG 素材。

适用人群

需要经常整理商品图片的电商运营、美工设计、选品专员，以及对淘宝 / 京东 / 拼多多详情页 图片有采集需求的个人开发者。

核心功能

从提取到下载，一条龙完成图片采集。

⤓

一键提取

详情页右下角「获取图片」按钮，点击即可抓取整页商品图片。

◫

全面覆盖

支持懒加载图、CSS 背景图、srcset 高清图，自动滚动触发加载。

▦

网格预览

新页面网格展示全部图片，支持单张勾选、全选、反选与清空。

⤢

大图预览

点击缩略图即可放大查看原图，挑选更精准。

⬇

PNG 批量下载

下载时统一转换为 PNG 格式，自动归档到「电商图片」文件夹。

◉

多平台适配

覆盖淘宝、京东、拼多多商家版三大平台，提取逻辑可扩展。

支持平台
淘宝 天猫 京东 拼多多商家版

安装步骤

三步完成安装，马上开始使用。

  1. 1

    打开扩展管理页

    在 Edge 浏览器地址栏输入 edge://extensions 并回车。

  2. 2

    开启开发人员模式

    打开页面左下角的「开发人员模式」开关。

  3. 3

    加载解压缩的扩展

    点击「加载解压缩的扩展」，选择插件项目根目录（包含 manifest.json 的文件夹）。

  4. 4

    开始使用

    进入淘宝 / 京东 / 拼多多商家版商品详情页，点击右下角「获取图片」按钮即可。
